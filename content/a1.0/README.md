# Контент A1.0

> Вариант с историей про Милу, отложен вместе с полной версией. Для MVP-lite материал лежит в lessons/A1.0 и написан для взрослой ученицы без истории.

Машинный контент слоя A1.0 для MVP по спецификации spec/06 и истории spec/09. Формат JSON, одна сущность на файл, кодировка UTF-8. Все тексты подсказок написаны для ученицы, которая играет Милу, семь лет; русские формы женского рода.

## Плейсхолдеры

В немецких шаблонах: {name}, {city}, {country}, {lang}, {adj}, {inf}, {akkIndef}, {akkNeg}, {nomIndef}, {nomDef}, {poss}, {nom}, {n}. В русских подсказках: {ru}, {ruAkk}, {ruGen}, {ruInf}, {ruState}, {ruSpeak}, {ruFrom}, {ruIn}, {ruAskM}, {ruAskF}. Генератор берёт заполнитель из списка fillerIds варианта или клетки, подставляет немецкую форму по имени плейсхолдера и русскую форму по имени плейсхолдера. Если у подсказки есть fillerId, заполнитель фиксирован.

Формы существительного: nomIndef «ein Kaffee», akkIndef «einen Kaffee», akkNeg «keinen Kaffee», nomDef «der Kaffee», poss «mein Kaffee». У неисчисляемых akkIndef без артикля: «Zeit», «Hilfe», «Wasser». У людей и имён nomDef без артикля: «Mama», «Tom».

## Правила, которые проверяет tools/validate-content.py

1. Все идентификаторы уникальны и все ссылки существуют.
2. Слово ядра модуля подходит хотя бы одному паттерну модуля или сцене.
3. У каждого варианта паттерна не меньше трёх подсказок, из них не меньше одной сюжетной.
4. Последовательность: примеры паттерна, шаблоны вариантов и клеток, реплики ученицы в сценах используют только слова, введённые к этому модулю. Реплики тьютора не проверяются, слова на понимание перечислены в главе.
5. У пассивного слова нет производственных форм в шаблонах.
6. У каждого модуля с типом pattern или engine есть сцена и глава.

## Как пересобрать обзор

```bash
python3 tools/validate-content.py content/a1.0 && python3 tools/content-overview.py content/a1.0
```

## Дополнения к формату

- У варианта паттерна заполнители задаются либо списком fillerIds, тогда немецкая форма берётся по имени плейсхолдера, либо списком fillers с объектами id, form, ru, когда форму и русский текст нужно задать вручную. Значение fillerIds "numbers" означает числа из numbers.json.
- Фиксированное предложение может иметь поле module, если оно становится доступным позже, чем сам паттерн.
- Слова с item: false служебные: у них нет карточки и бокса, они нужны валидатору и генератору.
- Проверка последовательности разрешает в репликах ученицы слова из receptiveWords главы, потому что они цитируются: Was bedeutet „Spielplatz“?
