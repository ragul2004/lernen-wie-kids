# Задание: плеер уроков для проверки обучения

Самодостаточное задание для модели или разработчика с чистым контекстом. Прочитать этот файл, затем lessons/A1.0/json/README.md и spec/MVP-LITE.md. Остальной репозиторий читать не нужно.

> Состояние на 2026-09-13: задание выполнено. Плеер лежит в index.html и player/, запускается через `docker compose up` на http://localhost:8091, см. README.md. Приёмка из этого файла пройдена. Сверх задания: плеер читает манифест lessons/index.json и показывает все слои; добавлен слой A1.1, уроки 10–24 в lessons/A1.1 с тремя новыми фактами {профессия}, {возраст}, {адрес}; с 2026-09-17 плеер хранит прогресс в localStorage (ключ lwk.progress): урок, дошедший до конца, отмечен в списке как пройденный с датой, начатый показывает достигнутую карточку, D в списке ставит отметку вручную, есть полоса «пройдено N из M» и сброс.

## Что построить

Локальный плеер уроков на одном экране. Загружает урок из lessons/A1.0/json/urok-NN.json и показывает карточки по одной. Тьютор и ученица сидят перед одним ноутбуком, тьютор управляет клавиатурой, ученица говорит вслух. Ничего не сохраняется, кроме фактов ученицы. Никакого сервера, кроме статического, никаких учётных записей, никакой сети.

## Зачем это, в шести строках

Ученица с нуля учит немецкий не по правилам, а готовыми конструкциями: «Ich möchte + действие», «Kann ich + действие?». Каждая встреча с конструкцией это попытка вспомнить до показа ответа, вслух, с немедленной обратной связью. Уроки уже расписаны по карточкам: слова, показ, эхо, пропуск, задание, карусель, трансформация, обратный перевод, сцена. Повторение старого встроено в уроки заранее, поэтому плееру не нужна никакая логика расписания. Единственная логика: ответ скрыт до нажатия, и что не получилось, показывается ещё раз в конце блока и в конце урока. Мы проверяем, работает ли сама стратегия, поэтому всё остальное убрано.

## Входные данные

- lessons/A1.0/json/urok-01.json … urok-09.json: карточки. Схема и типы в lessons/A1.0/json/README.md. Всего 9 уроков, около 1200 карточек, из них 773 с ответом.
- Факты ученицы: {имя}, {имя фамилия}, {город}, {страна}, {откуда}, {языки}, {семья}. Вводятся один раз на экране фактов и подставляются в тексты карточек. Если факт пуст, плейсхолдер показывается как есть.
- lessons/A1.0/urok-NN.md: те же уроки для чтения человеком. Не парсить.

## Экраны

Три экрана: список уроков, факты, плеер.

```
┌──────────────────────────────────────────────────────────────┐
│ Урок 4 · 3. Новое · П7 · Целиком                   12 из 134 │  шапка
│                                                              │
│                                                              │
│              Скажи, что хочешь пойти домой                   │  prompt, не меньше 36 px
│                                                              │
│                  Ich möchte nach Hause gehen.                │  answer, появляется по Space
│                                                              │
│                                                              │
│ Space ответ · Enter дальше · R повторить позже · ← назад     │  подвал
└──────────────────────────────────────────────────────────────┘
```

Шапка: номер и название урока, название блока, последний heading, позиция в уроке. Подвал: подсказка клавиш. Между шапкой и подвалом только карточка. Тип карточки показывается маленькой меткой над текстом: Пропуск, Целиком, Карусель, Трансформация, Слово, Вопрос, Сцена.

## Как показывать карточки

| Тип | На экране | Клавиши |
|---|---|---|
| heading | крупный заголовок раздела | Enter |
| label, note, echo | текст; note с tutorOnly мелко и серым | Enter |
| word | de крупно, ru под ним, example мелко | Enter |
| formula | de крупно, when мелко | Enter |
| show | de крупно, ru мелко | Enter |
| show_pair | from, стрелка вниз, to | Enter |
| cloze, task, carousel, transform, word_task, answer_question, scene_turn | prompt крупно, answer скрыт; после Space answer крупно под prompt | Space показать, Enter дальше, R повторить позже |
| reverse | de крупно, подпись «скажи смысл по-русски» | Enter |
| scene_line | speaker мелко, text обычным размером; тьютор читает вслух | Enter |
| summary | текст блоком | Enter |

Enter на карточке с ответом до Space тоже допустим: показывает ответ и не переходит дальше; второй Enter переходит. Backspace или стрелка влево возвращает на предыдущую карточку. Esc возвращает к списку уроков с подтверждением.

## Повтор

- R на карточке с ответом добавляет её в список повтора урока и показывает короткую отметку «в повтор». Повторное R снимает.
- При переходе к следующему блоку, если список не пуст, карточки из списка показываются подряд ещё раз, потом блок продолжается. Карточка остаётся в списке, если на повторе снова нажали R, иначе снимается.
- В блоке, название которого начинается с «6. Повтор» или содержит «Разбор», список показывается целиком ещё раз, потом блок продолжается.
- Список живёт только в памяти до конца урока.

## Не делать

Учётные записи, сервер с состоянием, журнал попыток, таймеры и статистика, режим для ученицы дома, история и персонажи, озвучка как обязательная часть, синхронизация двух экранов, редактирование уроков внутри приложения.

## Технические рамки

- Один HTML-файл или HTML плюс JS и CSS без шага сборки. Открывается через простой статический сервер, например python3 -m http.server в корне репозитория; JSON подгружается через fetch по относительному пути lessons/A1.0/json/.
- Без внешних библиотек. Chrome и Safari на ноутбуке. Клавиатура обязательна, мышь по желанию.
- Крупный текст: prompt и answer не меньше 36 px, читаемо с метра. Никаких анимаций, которых нужно ждать.
- Факты хранятся в localStorage; всё остальное только в памяти.
- Необязательно: клавиша T озвучивает немецкий текст текущей карточки через window.speechSynthesis с голосом de-DE, если он есть.

## Приёмка

1. Урок 1 проходится от первой до последней карточки только клавишами Space, Enter, R, Backspace.
2. Ни у одной карточки с answer ответ не виден до Space или Enter.
3. Плейсхолдеры заменяются на факты; при пустых фактах показываются как есть.
4. R добавляет карточку в повтор; повтор появляется при смене блока и в блоке «Повтор».
5. В шапке видны урок, блок, раздел и позиция.
6. Все девять уроков открываются; число карточек совпадает с таблицей в lessons/A1.0/json/README.md.
7. Работает без сети и без каких-либо серверов, кроме статического.

## Как проверить себе перед сдачей

Открыть урок 4, дойти до блока «3. Новое», убедиться, что после heading «П7. Желание, и внутри него рамка Д2» идут три show, потом echo, потом cloze с пропусками, потом task, потом carousel, потом transform, потом reverse. Нажать R на двух карточках, перейти в блок «4. Скрещивание» и увидеть их ещё раз.
