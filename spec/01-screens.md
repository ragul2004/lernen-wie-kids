# 01 Экраны

## Два экрана, одно состояние

Решение: два экрана. Экран ученика показывает только то, что ученику положено видеть. Пульт тьютора показывает всё и принимает все команды. Оба подключены к одному сеансу занятия на сервере: любое действие на пульте меняет состояние сеанса, и оба экрана перерисовываются из него. Один экран с двумя зонами остаётся запасным режимом на случай, когда второго устройства нет.

Почему один экран не подходит:

- Ожидаемый ответ и допустимые альтернативы нужны тьютору до оценки, а ученику только после.
- Служебные сведения о задании: холодный тест, трудное слово, активная путаница, бокс, следующие три задания. Ученику они мешают.
- Реплики тьютора в ситуации ученик должен слышать, а не читать.
- Причины красного, заметки тьютора, слабости и рекомендации ученику не показываются.
- На экране ученика должно быть пусто: подсказка, ответ после оценки, прогресс.

### Устройства

| Роль | Устройство | Что делает |
|---|---|---|
| Экран ученика | Планшет, второй монитор, телевизор, окно браузера | Показывает. Ввода нет, кроме необязательной кнопки «сказал» |
| Пульт тьютора | Телефон, планшет или окно браузера на ноутбуке | Управляет: кнопки, причины, подсказки, план, обзор |
| Сервер сеанса | Ноутбук тьютора или хостинг | Хранит состояние, журнал и контент, рассылает изменения |

Оба клиента это браузер. Экран ученика открывается по адресу сервера и коду сеанса из четырёх символов, который показывает пульт. Одно устройство с двумя окнами работает так же: два окна, один сеанс, второе окно на внешнем мониторе или телевизоре.

### Как идёт синхронизация

1. Пульт отправляет команду: «оценка зелёный», «причина слово», «показать», «следующее».
2. Сервер применяет команду к состоянию сеанса, при оценке пишет попытку в журнал, увеличивает номер версии состояния.
3. Сервер рассылает новое состояние обоим клиентам. Каждый клиент рисует свой вид из одного и того же состояния: экран ученика берёт публичную часть, пульт всю.
4. Клиент, который подключился или переподключился, сначала получает полный снимок состояния, потом изменения.

Транспорт: постоянное соединение, WebSocket или равноценное. Требования:

- Задержка от нажатия на пульте до перерисовки экрана ученика не больше 200 мс в локальной сети.
- Каждая команда несёт идентификатор и номер версии состояния, к которой относится. Команда с устаревшей версией отклоняется, пульт перерисовывается из свежего состояния.
- Повторно доставленная команда с тем же идентификатором применяется один раз.
- Время реакции считает сервер: момент показа задания и момент команды оценки берутся по его часам. Клиентские часы не участвуют.

### Обрывы связи

| Что случилось | Экран ученика | Пульт | Сеанс |
|---|---|---|---|
| Экран ученика отключился | | Плашка «экран ученика не подключён», кнопка «показать код»; можно продолжать, тьютор читает подсказки вслух | продолжается |
| Пульт отключился | Через 5 секунд «Пауза», таймер задания остановлен | | ждёт; при возврате пульт получает снимок |
| Сервер недоступен | «Пауза» | «Нет связи», кнопки заблокированы; последние команды хранятся и отправляются при возврате | восстанавливается из журнала |

### Один экран как запасной режим

Если второго устройства нет, пульт и экран ученика открываются в одном окне: сверху зона ученика, снизу полоса тьютора без ожидаемого ответа. Ответ и альтернативы появляются только после оценки или по «показать». Служебные сведения о задании скрыты. Обзор открывается только в безопасном виде без слабостей и рекомендаций. Режим считается запасным и не должен влиять на архитектуру: это тот же пульт и тот же экран ученика в одном окне.

## Режимы

| Режим | Клиент | Что там |
|---|---|---|
| Экран ученика | экран ученика | Подсказка, сцена, ответ после оценки, прогресс блока; презентационные виды по команде с пульта |
| Пульт | пульт тьютора | Текущее задание с ответом и служебными сведениями, кнопки, план, обзор, заметки |
| Обзор | пульт тьютора | Состояние ученика, слабости, рекомендации, план занятия, карты, история |
| Самостоятельно | ученик дома, один клиент | Слова на завтра, самопроверка, тень, Моя карточка, карта мест |


### Что показывается

| Элемент | Когда |
|---|---|
| Блок и позиция | всегда |
| Кольцо таймера без цифр | пока задание ожидает ответа; цифры только если тьютор включил «таймер ученику» |
| Сцена | блок «Ситуация» и задания с местом |
| Подсказка | с момента показа задания |
| Чип паттерна | стадии 2–4 нового паттерна; в разогреве и веере скрыт |
| Чип движка и базовое предложение | задания движка и клеток |
| Ответ с озвучкой | после оценки или после «показать» |
| Значок результата | ✓ зелёный, ~ жёлтый, ↻ красный со словом «повтори»; слова «красный» на экране нет |
| Прогресс блока | всегда; заполненные точки это пройденные задания без цвета |
| Презентационный вид | по команде с пульта: итог занятия, Моя карточка, карта мест, карта языка |

### Чего на экране ученика нет никогда

Ожидаемого ответа до оценки, альтернатив, причин красного, служебных сведений о задании, очереди, реплик тьютора в ситуации, слабостей, рекомендаций, заметок.

### Кнопка «сказал»

Необязательна, по умолчанию выключена. Если включена, ученик касается экрана, когда договорил; сервер записывает момент окончания речи отдельно от момента оценки. Оценка всё равно за тьютором. Нужна для более точной скорости, когда тьютор медлит с кнопкой.

## Пульт тьютора

Телефон вертикально; на планшете и ноутбуке те же блоки в две колонки.

```
┌──────────────────────────────────┐
│ A1.1 · Занятие 12 · Разогрев 14/30│
│ ⏱ 2.3 с          бюджет блока 6:40│
├──────────────────────────────────┤
│ Ученик видит                     │
│ «Скажи, что вечером ты любишь    │
│  готовить»              П22 · gern│
├──────────────────────────────────┤
│ Ожидается                        │
│ Am Abend koche ich gern.         │
│ Также: Ich koche gern am Abend.  │
│ П22 · бокс 2 · холодный тест     │
│ слово kochen: слабое, 1 жёлтый   │
├──────────────────────────────────┤
│ [       1  Зелёный       ]       │
│ [ 2  Жёлтый ] [ 3  Красный ]     │
│ [H] [показать] [Z] [S] [P]       │
├──────────────────────────────────┤
│ Дальше: П26 · Zeit · Д3 × П9     │
│ [план]  [обзор]  [заметка]  [▶ученику]│
└──────────────────────────────────┘
```

### Элементы

| Элемент | Что показывает | Когда |
|---|---|---|
| Шапка | Слой, занятие, блок, позиция, таймер с цифрами, остаток бюджета блока | всегда |
| Ученик видит | Точная копия подсказки и чипов с экрана ученика | всегда |
| Ожидается | Ожидаемый ответ, допустимые альтернативы с условиями, тип и номер единицы, бокс, метки: холодный тест, развал, трудное, путаница; для слова-заполнителя его состояние | всегда, до оценки |
| Кнопки цвета | 1, 2, 3 | пока задание ожидает оценки |
| Подсказка H | Ученику показывается первое слово ответа или чип паттерна | до оценки |
| Показать | Ученику показывается ответ целиком | до оценки |
| Отмена Z | Отменяет последнюю оценку; допустима одна отмена подряд | в течение следующего задания |
| Пропустить S | Задание в конец очереди блока без оценки; второй S на то же задание запрещён | до оценки |
| Пауза P | Останавливает таймер, экран ученика показывает «Пауза» | всегда |
| Причина | Шесть чипов на месте кнопок цвета: слово, артикль, форма, порядок, движок, не вспомнил; обязательна | после красного |
| Дальше | Следующие три задания очереди | всегда |
| План | Открывает план занятия с правками: изменить модуль, добавить веер, убрать новое | всегда |
| Обзор | Открывает экран обзора | всегда |
| Заметка | Свободный текст к текущей единице; хранится в её карточке | всегда |
| Ученику | Отправить на экран ученика презентационный вид: итог, Моя карточка, карта мест, карта языка; повторное нажатие возвращает занятие | всегда |

Клавиши на ноутбуке: 1, 2, 3, H, пробел для «показать» и «следующее», Z, S, P, D для обзора. На телефоне всё касанием, кнопки не меньше 56 px в высоту.

### Жизненный цикл одного задания

1. Показ. Сервер фиксирует момент показа; экран ученика показывает подсказку и запускает кольцо; пульт показывает подсказку, ожидаемый ответ и служебные сведения.
2. Ответ. Ученик говорит вслух. Экраны не меняются.
3. Оценка. Тьютор нажимает 1, 2 или 3. Сервер фиксирует момент, считает время реакции, пишет попытку.
4. Причина. При красном на пульте вместо кнопок цвета шесть чипов; следующее задание не показывается, пока причина не выбрана.
5. Обратная связь. Экран ученика показывает ответ, значок и озвучку. При жёлтом и красном ученик повторяет ответ вслух, тьютор нажимает «следующее». При зелёном «следующее» или автопереход через 1,5 секунды.
6. Следующее задание.

Исключения: H до оценки ограничивает результат жёлтым; «показать» до оценки даёт красный с причиной «не вспомнил»; Z удаляет последнюю попытку и показывает задание заново; при 20 секундах без нажатий пульт подсвечивает кнопки, ничего не записывается автоматически.

### Подэкраны нового паттерна

Семь шагов протокола из 03. Пульт показывает номер шага, инструкцию, критерий прохода и счётчик; экран ученика показывает только то, что нужно для шага.

| Шаг | Экран ученика | Пульт |
|---|---|---|
| 1 Смысл и звук | Функция по-русски, формула с подсвеченным гнездом, три примера крупно с переводом и озвучкой | То же плюс строка «что сказать ученику: меняется только то, что после möchte» |
| 2 Эхо | Один пример на экран, озвучка, подпись «повтори» | Счётчик кругов 1 из 3, кнопка «следующее» |
| 3 Пропуск | Немецкое с пропуском и русский смысл; после оценки пропуск заполняется | Ответ, кнопки |
| 4 Целиком | Подсказка; счётчик «подряд: ● ● ○» | Ответ, счётчик, кнопки |
| 5 Карусель | Подсказка, десять точек сверху, полоска 4 секунды как ориентир | Ответ, счёт 6 из 8 нужных, кнопки; следующее задание сразу после нажатия |
| 6 Трансформации | Базовое предложение и чип движка | Ответ, список движков, какие уже пройдены |
| 7 Обратно | Немецкое предложение и озвучка | Русский смысл, две кнопки «понял», «не понял» |

### Ситуация

Экран ученика показывает сцену, роли и подсказку к своей реплике; реплик тьютора на нём нет. Пульт показывает весь сценарий с выделенной текущей репликой: реплика тьютора крупно, чтобы читать вслух, подсказка ученика и ожидаемый ответ под ней. Каждая реплика ученика оценивается кнопками без причины при красном. После сценария кнопка «свободно»: тот же диалог без подсказок на экране ученика, оценка одной кнопкой на весь диалог: «получилось», «с помощью», «не получилось».

### Итог занятия

Пульт показывает страницу тьютора: продвинулось, починено, развалы, домашние «не знал», причины красных, скорость по слоям, рекомендации. Кнопка «ученику» отправляет на экран ученика его страницу «Сегодня ты вырос» из 05.

## Экран обзора

Только на пульте. Секции сверху вниз:

| Секция | Содержание |
|---|---|
| Ученик | Имя, возраст языка, слой, число занятий, дней с последнего, серия занятий |
| План на сегодня | Тип занятия и состав: проверка слов, разогрев, модуль с паттернами, скрещивание, ситуация, ожидаемая длительность. Кнопки: изменить модуль, добавить веер, сделать сплошной веер, убрать новое |
| Слабости | Причины красных за три занятия по убыванию; трудные единицы; активные путаницы; здоровье слоёв; скорость по слоям |
| Рекомендации | Список из правил 06, у каждой кнопки «принять» и «скрыть»; принятая меняет план |
| Карты | Карта языка, перекрёстная карта, карта мест; у каждой кнопка «ученику» |
| Моя карточка | Текущий рассказ о себе, кнопка «ученику», правка фактов |
| История | Список занятий: дата, тип, зелёных, красных, что введено |

В запасном режиме одного экрана обзор открывается без секций «Слабости» и «Рекомендации».

## Режим самостоятельно

Ученик дома, один клиент, тот же сервер или локальный журнал с последующей отправкой. Главный экран показывает три задачи на сегодня и две карты.

| Экран | Что делает |
|---|---|
| Сегодня | Слова на завтра: 12, самопроверка: 28, тень: 1 диалог; прогресс по каждому |
| Слова | Карточки знакомства, три упражнения из 02: узнавание, вспоминание, слух |
| Самопроверка | Подсказка; ученик думает и говорит вслух; «показать»; ответ и озвучка; ученик повторяет; две кнопки «знал», «не знал» |
| Тень | Озвученный демо-диалог модуля построчно, ученик повторяет за записью; без оценки |
| Моя карточка | Как в 05, только чтение и озвучка |
| Карта мест | Как в 05 |

Правила режима: таймер не показывается, время до «показать» пишется; кнопок две; «не знал» не роняет бокс, а ставит единицу первой в следующий разогрев; после «показать» повтор вслух обязателен, кнопки появляются через две секунды после ответа. Попытки, сделанные без связи, хранятся на устройстве и отправляются при следующем подключении; правила слияния в 06.

## Переходы занятия

| Из | В | Условие |
|---|---|---|
| Старт | Проверка слов | сегодня открывается модуль с непроверенными словами |
| Старт | Разогрев | иначе |
| Проверка слов | Разогрев | всегда; результат решает, будет ли модуль |
| Разогрев | Новое | тип занятия паттерн или движок, слова готовы, красных в разогреве не больше 20 % |
| Разогрев | Новое, один паттерн | красных в разогреве больше 20 % |
| Разогрев | Веер вместо нового | модуль перенесён: больше 30 % слов не готовы |
| Новое | Скрещивание | все паттерны модуля прошли шаги 1–7 |
| Скрещивание | Ситуация | всегда |
| Ситуация | Починка | всегда |
| Починка | Итог | все красные занятия показаны второй раз |
| Итог | Слова на завтра | если следующее занятие открывает модуль |
| Слова на завтра | Конец | всегда: формируется домашняя очередь |
| Сплошной веер | Итог | 60 заданий пройдены |
| Ворота | Итог | все задания ворот пройдены, демо-диалоги записаны |

## Доступность и темп

- Экран ученика читается с полутора метров: подсказка не меньше 40 px, ответ не меньше 32 px.
- Результат всегда дублируется значком, а не только цветом.
- Никаких анимаций, которых нужно ждать; переходы не дольше 200 мс.
- Пульт на ноутбуке полностью управляется клавиатурой; на телефоне касанием.
- Озвучка через системный синтез речи с немецким голосом на экране ученика; если голоса нет, кнопка озвучки скрыта, тьютор читает сам.

## Приёмка

1. Экран ученика никогда не показывает ожидаемый ответ до оценки или «показать».
2. Нажатие на пульте отражается на экране ученика не позже чем через 200 мс в локальной сети.
