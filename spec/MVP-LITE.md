# MVP-lite

Минимальная версия, чтобы попробовать стратегию без кода. Один экран, тьютор рядом с ученицей, никаких аккаунтов, домашних заданий, истории и сбора данных. Всё, что нужно, это уроки по разделам, расписанные пошагово, и три правила проведения. Документы 00–09 описывают полную версию и на этом этапе не действуют.

## Как это выглядит

Экран один, ноутбук между тьютором и ученицей. Урок это последовательность карточек, их листают вперёд. Пока это документ, карточка это строка таблицы; если позже делать приложение, то это плеер уроков: одна карточка на экран, кнопка «дальше», кнопка «показать ответ».

```
┌────────────────────────────────────────────────────────┐
│ Урок 4 · Новое · П7 · Целиком · 3 из 6                 │
│                                                        │
│                                                        │
│          Скажи, что хочешь пойти домой                 │   подсказка, крупно
│                                                        │
│                                                        │
│               [ показать ответ ]                       │   ответ скрыт до попытки
│                                                        │
│  после нажатия:   Ich möchte nach Hause gehen.         │
│                                                        │
│                          [ ✓ дальше ]   [ ✗ повторить позже ] │
└────────────────────────────────────────────────────────┘
```

Виды карточек:

| Карточка | Что на экране | Что делает ученица |
|---|---|---|
| Слово | Немецкое слово с артиклем, значение, пример | Повторяет дважды за тьютором |
| Показ | Три немецких предложения с переводом | Слушает, потом повторяет |
| Пропуск | Предложение с пропуском и русский смысл | Говорит предложение целиком |
| Задание | Русская подсказка; ответ скрыт | Говорит вслух, потом ответ показывают |
| Трансформация | Немецкое предложение и инструкция: «спроси», «скажи, что не …» | Говорит преобразованное предложение |
| Обратно | Немецкое предложение | Говорит смысл по-русски |
| Сцена | Реплика тьютора мелко, подсказка ученице крупно | Отвечает; тьютор читает свои реплики вслух |

## Три правила проведения

1. Сначала попытка, потом ответ. Тьютор молчит первые пять секунд и не показывает ответ, пока ученица не попробовала.
2. После ответа ученица один раз повторяет правильную фразу вслух, даже если сказала верно.
3. Что не получилось, тьютор отмечает номером на бумаге или кнопкой «повторить позже» и возвращает в конце блока и в конце урока.

Никакой другой логики нет. Повторение старого материала уже зашито в уроки: каждый урок начинается с разогрева из предыдущих, а восьмой и девятый уроки целиком проверочные.

## Что в уроке

| Блок | Минут | Содержание |
|---|---|---|
| Слова урока | 10 | Слова урока с примерами; тьютор читает, ученица повторяет; в конце быстрый круг «по-русски → по-немецки» |
| Разогрев | 10 | 20–25 заданий из прошлых уроков вперемешку, быстро, без объяснений |
| Новое | 20 | Каждый паттерн: показ, эхо, пропуск, целиком, карусель, трансформации, обратно |
| Скрещивание | 8 | Новое вперемешку со старым |
| Сцена | 7 | Диалог по сценарию, потом свободно |
| Повтор | 5 | Всё, что не получилось за урок |
| Итог | | Что ученица теперь умеет сказать; тьютор читает вслух |

Уроки для слоя A1.0 лежат в lessons/A1.0: семь уроков с новым материалом, сплошная проверка и ворота.

## Если позже делать приложение

Нужен только плеер карточек: загрузить урок, показывать карточки по одной, скрывать ответ до нажатия, помнить номера «повторить позже» в пределах урока. Никакого сервера, никаких учётных записей, никакого журнала. Всё остальное из документов 00–09 добавляется потом, если стратегия себя покажет.
