## Переходы состояний

Стадии единиц в 03, состояния слова в 02, боксы в 04. Инварианты:

- Стадия 6 требует бокс не ниже 3.
- Слово в фазе 1 не имеет бокса; бокс появляется при переходе в состояние 4.
- Клетка создаётся в момент первого задания на неё, стадия клетки не ведётся, только бокс и цвет.
- Формула ведётся как паттерн без гнезда.

## Правила

Номер, условие, действие. Константы из 00.

| № | Условие | Действие |
|---|---|---|
| R01 | Ответ зелёный | streak +1; если это второй зелёный в другом занятии, бокс +1 до 5 |
| R02 | Ответ жёлтый | streak без изменений; единица в очередь возврата занятия |
| R03 | Ответ красный, бокс ниже 3 | streak 0; бокс 1; возврат через 5 заданий и в починке |
| R04 | Ответ красный, бокс 3 и выше | флаг collapse; бокс 2; сокращённые шаги 3–5 в этом занятии; соседи в следующий разогрев |
| R05 | Красный с причиной | запись результата по таблице из 02 |
| R06 | Три красных в разных занятиях | флаг hard; рекомендация тьютору |
| R07 | Единица должна по боксу | занятий с lastSeenSession не меньше интервала бокса |

## Правила рекомендаций

Рекомендация появляется в обзоре тьютора с кнопками «принять» и «скрыть». Принятие меняет план занятия.

| Правило | Триггер | Текст тьютору | Действие при принятии |
|---|---|---|---|
| РК1 | R18 | Артикли: 22 % ошибок. Добавить артикльный спринт | спринт в начало разогрева |
| РК2 | R04 с системными соседями | Perfekt с sein развалился в 4 клетках из 9. Повторить Д9 по шагам 1–4 | движок-повтор вместо новой части модуля |
| РК3 | R06 | Слово «Stunde» трудное: 3 красных. Мнемоника, ещё контексты или отложить | выбор из трёх |
| РК4 | R10 | Слова модуля не зашли: 5 из 12. Проверить домашний режим | модуль перенесён |
| РК5 | R23 | Самопроверки не было 3 дня. Разогрев длиннее, новое короче | план изменён |
| РК6 | скорость слоя выросла на 30 % за три занятия | A1.0 замедлился: 2,1 → 3,0 секунды. Добавить веер A1.0 | 10 заданий A1.0 в разогрев |
| РК7 | здоровье слоя ниже 85 % в сплошном веере | A1.1 держится на 82 %. Следующее занятие без нового | тип занятия веер |
| РК8 | паттерн на стадии 3–4 больше трёх занятий | П38 застрял. Повторить карусель и трансформации | шаги 5–6 в блоке «Новое» |
| РК9 | пара путаницы активна дважды за месяц | wohnen / wollen путаются. Дать контрастную серию на дом | серия в домашнюю очередь |
| РК10 | ворота через одно занятие | Ворота A1.1 через занятие. Сегодня сплошной веер вместо нового | тип занятия веер |

## Расчёты

| Показатель | Формула |
|---|---|
| Здоровье слоя | доля зелёных среди заданий слоя в последнем сплошном веере или воротах |
| Скорость слоя | медиана latencyMs зелёных ответов по единицам слоя за занятие |
| Возраст языка | по таблице 05; внутри слоя: доля паттернов слоя на стадии 5 и выше |
| Счётчик мыслей | сумма по паттернам на стадии 3 и выше: число подходящих слов в состоянии 4 и выше; для паттернов без гнезда 1 |
| Автоматизация слоя | доля единиц слоя на стадии 6 |
| Домашняя очередь | единицы 3-2-1, потом должные в следующем занятии, потом слабые; не больше 40 |
| Готовность модуля | все coreWordIds в состоянии 3 и все passiveWordIds в состоянии 2 |

## Формат контента

Контент хранится в текстовых файлах, по одному на тип. Ниже по одному примеру записи. Пробелы и переносы не значимы, значимы имена полей.

```
pattern:
  id: П7
  layer: A1.0
  functionRu: Желание
  templateDe: Ich möchte {slot}
  slots:
    - name: slot
      wordClass: noun-akk | infinitive
  cueTemplatesRu:
    - text: Ты хочешь {slotRu}                voice: neutral
    - text: Тебе хочется {slotRu}             voice: neutral
    - text: Скажи, что хотел бы {slotRu}      voice: neutral
    - text: Скажи маме, что хочешь {slotRu}       voice: story
    - text: Скажи официанту, что хочешь {slotRu}  voice: story
  examples:
    - de: Ich möchte einen Kaffee.   ru: Я хотел бы кофе.
    - de: Ich möchte schlafen.        ru: Я хочу спать.
    - de: Ich möchte Deutsch lernen.  ru: Я хочу учить немецкий.
  alternatives:
    - de: Ich will {slot}            when: cue neutral
    - de: Ich hätte gern {slot}      when: cue polite, slot noun
  applicableEngines: [Д3, Д4, Д5, Д6, Д16, Д17]
  placeIds: [cafe, supermarkt]
  ichTemplate: Ich möchte {hobbyInfinitive}.
  notes: Главный паттерн слоя. «einen Kaffee» пока чанк.
```

Проверки контента при загрузке: идентификаторы уникальны; каждое слово ядра модуля подходит хотя бы одному паттерну модуля; у каждого паттерна не меньше трёх шаблонов подсказки; все паттерны места существуют; у каждого модуля есть ситуация; у пассивного слова нет applicablePatternIds.

## Сеанс и команды

Состояние сеанса живёт на сервере. Пульт отправляет команды, экран ученика только получает состояние.

| Команда | Что несёт | Действие сервера |
|---|---|---|
| grade | color | фиксирует gradedAt, пишет попытку, при красном ставит phase awaitingReason, иначе feedback |
| reason | attribution | дописывает причину в последнюю попытку, phase feedback |
| next | | показывает следующее задание, фиксирует shownAt, phase showing |
| hint | | помечает hintUsed в текущем задании; публичная часть получает первое слово ответа |
| reveal | | публичная часть получает ответ; при отсутствии оценки создаётся красная попытка «не вспомнил» |
| undo | | удаляет последнюю попытку, возвращает предыдущее задание |
| skip | | задание в конец блока; повторный skip отклоняется |
| pause, resume | | phase paused и обратно |
| present | view | экран ученика показывает презентационный вид; повторный present без view возвращает занятие |
| spoke | | только от экрана ученика при включённой кнопке «сказал»; фиксирует speechEndAt |
| planChange | изменение плана | перестраивает очередь по 04 |

Публичная часть текущего задания: подсказка, чипы, сцена, базовое предложение, а после оценки ответ и значок. Служебная часть: ожидаемый ответ, альтернативы, тип и номер единицы, бокс, метки, состояние заполнителя, следующие три задания. Экран ученика получает только публичную часть; сервер не отправляет ему служебную ни в каком состоянии.

## Журнал

Всё состояние восстанавливается из Attempt и контента. Реализация может хранить кэш состояний единиц, но при расхождении верен журнал. Попытка неизменяема и имеет идентификатор, созданный на клиенте; сервер отбрасывает повтор по идентификатору. Попытки из домашнего режима, сделанные без связи, хранятся на устройстве и отправляются при подключении; порядок восстанавливается по времени клиента, состояние пересчитывается. Экспорт журнала в один файл нужен для переноса между установками и для разбора с тьютором.

## Приёмка

1. После удаления кэша состояния единиц восстанавливаются из журнала без потерь.
2. Каждое правило R01–R32 можно вызвать вручную заданной последовательностью попыток и получить описанное действие.
3. Загрузка контента с нарушенной проверкой останавливается с указанием записи.
4. Экран ученика при перехвате трафика не получает служебную часть задания.
5. Домашние попытки, отправленные дважды, попадают в журнал один раз.
