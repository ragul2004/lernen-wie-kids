# Lernen wie Kids

> Текущий путь: MVP-lite. Один экран, без истории, без домашних заданий, без сбора данных. Действуют три документа: HANDOFF.md, spec/MVP-LITE.md и уроки в lessons/A1.0 с их JSON-карточками, плюс плеер уроков (index.html и player/), собранный по HANDOFF.md и запускаемый в Docker. Всё остальное ниже описывает полную версию и отложено до тех пор, пока стратегия не будет проверена на живых занятиях.

Тренажёр немецкого для пары «тьютор плюс ученик»: слои A1 с нуля. Единица обучения это речевой паттерн, а не слово и не правило; слова учатся до модуля и живут внутри предложений; оценивает человек тремя кнопками; приложение ведёт очередь, боксы, веера и показывает рост. Сейчас в репозитории учебный материал, спецификация и плеер уроков для MVP-lite: статическая страница, которая листает карточки уроков A1.0.

Этот файл говорит, что где лежит, в каком порядке читать и что нужно понять до первой строчки кода MVP.

## Как запустить плеер

```bash
docker compose up
```

Открыть http://localhost:8091. Другой порт: `LWK_PORT=9000 docker compose up`. Без Docker то же самое даёт `python3 -m http.server 8000` в корне репозитория и адрес http://localhost:8000.

Клавиши в плеере: Space показать ответ, Enter дальше, R повторить позже, Backspace или стрелка влево назад, Esc к списку уроков, T озвучить немецкий текст, если в системе есть голос de-DE. На списке уроков номер урока набирается цифрами, F открывает факты ученицы, D ставит или снимает отметку «пройден» у выбранного урока. Урок, дошедший до конца, отмечается в списке галочкой с датой, числом прохождений и остатком повтора; начатый и брошенный показывает, до какой карточки дошли; сверху полоса «пройдено N из 24» и счётчик по слою, кнопка «сбросить прогресс» стирает отметки. Факты и прогресс хранятся в localStorage браузера, список повтора только в памяти до конца урока.

Папка lessons и файлы плеера примонтированы в контейнер с диска: после правки урока достаточно перегенерировать JSON и манифест и обновить страницу:

```bash
python3 tools/lessons-to-json.py lessons/A1.1 && python3 tools/lessons-index.py
```

На списке уроков номер набирается цифрами: «1» и «7» открывают урок 17; одна цифра открывает урок 1–9 через короткую паузу или по Enter, две цифры с возможным продолжением (10–19) ждут паузу. Пересборка образа нужна только после правок Dockerfile или docker/nginx.conf.

## Что нужно понять до первой строчки кода

1. Единица обучения это паттерн с гнездом. Слово это заполнитель гнезда. Движок это операция над паттернами. Клетка это паттерн, пропущенный через движок. У всех четырёх есть бокс и цвет, у паттерна и слова ещё стадия.
2. Единственный источник истины это журнал попыток. Попытка неизменяема и содержит единицу, режим, цвет, причину, время реакции, заполнители. Стадии, боксы, состояния слов, карта и итог выводятся из журнала и контента; кэш допустим, при расхождении верен журнал.
3. Один сеанс, два вида. Сервер держит состояние сеанса; пульт шлёт команды; экран ученика получает только публичную часть задания и не получает служебную ни в каком состоянии. Время реакции считает сервер.
4. Оценивает тьютор: зелёный, жёлтый, красный и шесть причин. Причина решает, кому записывается результат: паттерну, слову или клетке. Таблица в 02.
5. Боксы считаются в занятиях: интервалы 1, 2, 4, 8, 16. Вверх за два зелёных в разных занятиях, красный в бокс 1, развал из бокса 3 и выше в бокс 2 с меткой.
6. Внутри занятия красный возвращается через пять заданий и в починке, новая единица возвращается трижды. Один паттерн не идёт два раза подряд, предложение не повторяется дословно.
7. Слово живёт в двух фазах. Модуль открывается, когда все слова ядра в состоянии «Понял»; в MVP у тьютора есть кнопка «открыть всё равно».
8. Дом на платформе: схема 3-2-1, потом дневные интервалы 4, 7, 14, 30, 60. Домашнее «знал» не повышает бокс, «не знал» ставит единицу первой в следующий разогрев.
9. Задания генерируются из шаблонов: русские подсказки паттерна умножаются на подходящие известные заполнители; альтернативы показываются тьютору. В занятии нет LLM.
10. Все числа берутся из констант в 00 и лежат в настройках, не в коде.
