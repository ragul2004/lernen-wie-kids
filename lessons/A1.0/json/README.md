# Карточки уроков A1.0

Файлы urok-01.json … urok-09.json генерируются из markdown-уроков скриптом tools/lessons-to-json.py. Руками не править: правки вносятся в urok-NN.md, потом скрипт запускается заново. Источник истины для плеера это JSON.

## Структура файла

```
{
  "lesson": 1,
  "title": "Кто я, откуда, где живу",
  "blocks": [
    { "title": "1. Слова урока, 10 минут", "cards": [ … ] },
    …
  ]
}
```

Блок соответствует разделу урока: слова, разогрев, новое, скрещивание, сцена, повтор, итог. Карточки показываются по одной в порядке массива.

## Типы карточек

| type | Поля | Как показывать | Есть скрытый ответ |
|---|---|---|---|
| heading | text | Заголовок раздела внутри блока, например «П1. Представиться» | нет |
| label | text | Маленькая подпись перед серией: «Пропуск», «Целиком» | нет |
| note | text, иногда tutorOnly: true | Пояснение; с tutorOnly мелко, это для тьютора | нет |
| echo | text | Инструкция повторить показанное | нет |
| word | de, ru, example | Слово крупно, значение, пример | нет |
| formula | de, when | Формула крупно, когда её говорят | нет |
| show | de, ru | Немецкое предложение крупно, смысл мелко | нет |
| show_pair | from, to | Было и стало, две строки | нет |
| cloze | prompt, answer | Предложение с пропуском крупно | да |
| task | prompt, answer | Русская подсказка крупно | да |
| carousel | prompt, answer | Короткая подсказка крупно, темп быстрый | да |
| transform | prompt, answer | Немецкое предложение с инструкцией | да |
| word_task | prompt, answer | Русское слово, ответ слово с артиклем | да |
| answer_question | prompt, answer | Вопрос тьютора по-немецки, тьютор читает вслух | да |
| reverse | de | Немецкое предложение; ученица говорит смысл по-русски; ответа нет | нет |
| scene_line | speaker, text | Реплика тьютора мелко; он читает вслух | нет |
| scene_turn | prompt, answer | Подсказка ученице крупно; prompt может быть пустым на воротах | да |
| summary | text | Итог урока, несколько строк | нет |

## Плейсхолдеры

В prompt и answer встречаются {имя}, {имя фамилия}, {город}, {страна}, {откуда}, {языки}, {семья}. Плеер подставляет факты ученицы, введённые один раз; если факт не введён, показывает плейсхолдер как есть.
